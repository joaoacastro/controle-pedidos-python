# Controle de Pedidos

Sistema desenvolvido em Python para gerenciamento de clientes, produtos e pedidos de uma operação de vendas.

## Sobre o projeto

Este projeto está sendo desenvolvido como uma forma prática de estudar e reaprender Python através de uma aplicação real.

A ideia é criar, inicialmente, um sistema simples para:

- cadastrar e gerenciar clientes;
- cadastrar e gerenciar produtos;
- controlar disponibilidade de produtos;
- registrar pedidos;
- calcular valores das vendas;
- manter histórico das informações.

O projeto será desenvolvido de forma incremental, começando por uma versão simples executada pelo terminal e evoluindo posteriormente para persistência de dados e uma interface mais completa.
